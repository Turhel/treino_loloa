# Base Forge 90

O diretório [`forge90/`](forge90/) é um clone de trabalho de
[Oroshi-zz/Forge_90](https://github.com/Oroshi-zz/Forge_90), mantido sob
GNU AGPL-3.0-or-later.

Ele é a referência e base visual do novo Treino Loloa. Alterações feitas
dentro desse diretório continuam sujeitas à AGPL e devem preservar avisos de
copyright e atribuição do Forge 90.

As regras de treino específicas do Loloa serão portadas gradualmente para
Python, sem remover os avisos de origem do código que for reutilizado.
